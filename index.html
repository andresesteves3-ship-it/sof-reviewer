    Chave do GitHub para atualizar na hora

    Os botões "Atualizar agora" pedem ao GitHub que rode o robô. Para isso o GitHub exige uma chave (token). Ela fica salva só neste computador. Para criar (uma vez, no GitHub): Settings (do seu perfil) › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token. Em "Repository access" escolha Only select repositories › sof-reviewer. Em "Permissions › Repository permissions" marque Actions: Read and write. Gere, copie e cole abaixo.

    Chave de acesso do Line Up

    Os dados do Geport lidos pelo robô ficam criptografados no GitHub. Digite a chave combinada com a equipe (a mesma cadastrada como LINEUP_KEY no GitHub). Ela fica salva só neste computador.

    Ainda não há dados. Siga o passo a passo abaixo para trazer a lista do Geport.
    Como atualizar os dados (Geport e Praticagem)

    1) Uma única vez: mostre a barra de favoritos do navegador (Ctrl+Shift+B) e arraste os botões para ela:

    Enviar para o Line Up

    Se o navegador não deixar arrastar: clique com o botão direito no botão, “Copiar endereço do link”, crie um favorito novo e cole no campo URL.

    2) Navios (Geport): um robô no GitHub entra no Geport a cada hora e envia a lista (criptografada). Para ler, digite a chave de acesso quando o Line Up pedir. Se o robô falhar ou você quiser atualizar na hora, use o favorito: abra Frente de Trabalho › Aquaviária no Geport e clique em Enviar para o Line Up. Ele lê a tabela que você está vendo (todas as páginas) e abre o Line Up atualizado.

    3) Manobras (Praticagem): um robô no GitHub lê o site da Praticagem a cada 1 hora e guarda o histórico (marcado, cancelado, voltou). O Line Up só mostra esse resultado e recarrega sozinho a cada 5 minutos. Para forçar uma leitura agora, use Atualizar Praticagem agora (ou Atualizar Geport agora para o Geport); na primeira vez o Line Up pede a chave do GitHub.

    O favorito do Geport só lê o que você já está vendo na tela. Não usam nem guardam senha, e os dados ficam apenas neste computador.

    Alternativa para o Geport: se o favorito avisar que copiou os dados, cole aqui:
